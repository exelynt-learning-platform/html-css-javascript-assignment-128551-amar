## Week 1 - Setup & Your First HTML Page: Favourite Movie

A simple web page about my favourite movie, **3 Idiots**.

### What it contains
- `index.html` with the basic HTML5 structure (`doctype`, `html`, `head`, `body`)
- A main heading with the movie name and a short paragraph about it
- An unordered list of three actors
- A poster image (`images/poster.svg`) with descriptive `alt` text
- A link to the movie's IMDb page (opens in a new tab)

### How to run
1. Clone the repository and open the folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server** (or just open the file in a browser).

### What I learned
- The basic structure of an HTML page
- Using headings, paragraphs, lists, images and links
- Writing useful `alt` text for images
- Working on a branch and pushing commits to GitHub
