## Week 1 - Styling with CSS: Recipe Card

A styled recipe card for **Masala Chai**.

### Files
- `recipe.html` - dish name, a short description and a list of ingredients
- `recipe.css` - all the styles, linked from `recipe.html` with a `<link>` tag

### What the CSS does
- Sets a warm background colour and a sans-serif font for the page
- Gives `h1` and `h2` their own colours
- Uses the box model (padding, border, border-radius) around the ingredient list
- Adds a `spicy` class to two ingredients (ginger and black pepper) so they appear in bold red with a "(spicy)" label

### How to run
Open `recipe.html` in a browser, or right-click it in VS Code and choose **Open with Live Server**.

### What I learned
- Linking an external CSS file
- Element and class selectors, colours and fonts
- The box model: margin, padding and border
- Reusing a class to style several elements
